# 復習ダッシュボード

毎日の復習対象をここで確認する。

## 優先復習（confidence 1-2）
```dataview
TABLE course, topic, status, confidence, date
FROM ""
WHERE status != "完了" AND number(confidence) <= 2
SORT confidence ASC, date DESC
```

## 学習中のノート
```dataview
TABLE course, topic, confidence, date
FROM ""
WHERE status = "学習中"
SORT date DESC
```

## 復習中のノート
```dataview
TABLE course, topic, confidence, date
FROM ""
WHERE status = "復習"
SORT confidence ASC, date DESC
```

## 科目別の件数
```dataview
TABLE length(rows) AS "件数"
FROM ""
GROUP BY course
SORT course ASC
```

## ステータス別の件数
```dataview
TABLE length(rows) AS "件数"
FROM ""
GROUP BY status
SORT status ASC
```

## 今週作成したノート
```dataview
TABLE course, topic, status, confidence, date
FROM ""
WHERE date >= date(today) - dur(7 days)
SORT date DESC
```

## 期限が近い課題
```dataview
TABLE course, topic, assignment_status, due, repo
FROM ""
WHERE due AND assignment_status != "提出済"
SORT due ASC
```

## 課題進捗一覧
```dataview
TABLE course, topic, assignment_status, due
FROM ""
WHERE assignment_status
SORT assignment_status ASC, due ASC
```

## 未転記の用語カード（授業中メモ）
```dataview
TASK
FROM ""
WHERE contains(text, "#termcard") AND !completed
SORT file.mtime DESC
```

## 試験優先度Aの用語
```dataview
TABLE course, term, exam_scope, importance, from_note
FROM ""
WHERE contains(tags, "glossary") AND exam_priority = "A"
SORT importance DESC, file.name ASC
```
