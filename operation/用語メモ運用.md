# 用語メモ運用

## 結論
- 授業メモと単語メモは分ける
- ただし全単語は切り出さず、再登場する重要語だけを単語メモ化する
- 用語の一次情報は授業中に `#termcard` で残す（後から思い出して書かない）

## 単語メモ化する基準
- 同じ授業内で2回以上出た語
- 別科目でも出る語（例: 認証、可用性、正規化）
- 試験頻出語、または定義を正確に問われる語
- 自分が説明しにくい語（confidence が低い語）

## 最小運用
1. 授業ノートでは、授業中に `#termcard` を使ってミニ用語カードを記録する
2. 授業後10分で「重要語だけ」`operation/templates/term_template.md` へ転記する
3. 転記後は `#termcard` のタスクを完了チェックする
4. 授業ノート側に `[[単語ノート名]]` を貼る

## ミニ用語カード書式
```text
- [ ] #termcard 用語:  | 一言定義:  | 例:  | 重要: 試験/実務 | 転記先: [[ ]]
```

## メリット
- 授業ログ（時系列）と知識辞書（概念整理）を両立できる
- テスト前に単語ノートだけを回せる
- 将来の就活・面接で説明練習に再利用しやすい
