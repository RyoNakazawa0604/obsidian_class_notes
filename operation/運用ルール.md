# Obsidian Class 運用ルール

## 目的
- ノートの検索性を上げる
- 復習時に迷わない構成を維持する
- Dataview で一覧・進捗管理しやすくする

## 1. ファイル名ルール
- 形式は `course_topic_number.md` を基本にする
- 文字は半角英数字・`_` のみ（空白は使わない）
- 例: `security_law_1.md`, `system_design_process_2.md`
- 既存の科目フォルダは維持（`hardware`, `security`, `system_design` など）

## 2. Frontmatter ルール
すべての学習ノートで以下を必須にする。

```yaml
---
date: 2026-04-30
course: security
topic: インターネット関連の法規
status: 未着手
confidence: "1"
tags:
  - security
  - 基本情報技術者試験
  - qualification_test_2
aliases:
---
```

- `topic` は空欄禁止（ノートの要約タイトルとして必ず記入）
- `status` は `未着手 / 学習中 / 復習 / 完了` の4種類に統一
- `confidence` は `"1"` から `"5"` の文字列で記入

## 3. タグルール
- 1つ目: 科目タグ（例: `security`）
- 2つ目: 試験系タグ（例: `基本情報技術者試験`）
- 3つ目: 区分タグ（例: `qualification_test_1`）
- 必要なら4つ目以降に詳細タグを追加（例: `法規`, `ネットワーク`）

## 4. ノート作成フロー
1. `templates/template1.md` から新規作成
2. ファイル名を命名ルールで保存
3. Frontmatter の `topic/status/confidence/tags` を先に埋める
4. 本文は「見出し -> 箇条書き -> 必要なら内部リンク」で記述
5. 作成後に `status` と `confidence` を見直す

## 5. 内部リンクルール
- 関連語は `[[ノート名#見出し|表示名]]` でリンク
- 同一テーマ内で最低1つは相互リンクを作る
- 新規ノート作成時、既存ノートから1本リンクを張る

## 6. 週次メンテ（10分）
- 空欄チェック: `topic`, `tags`, `aliases`
- `status: 学習中` のノートを優先復習
- `confidence` が `"1"` または `"2"` のノートを再学習
- ファイル名に空白があるノートをリネーム

## 7. 当面の改善タスク
- `topic` 空欄ノートを埋める
- 空白入りファイル名を順次統一する
- Dataview で `status` と `confidence` の一覧ノートを作る
