# プロパティ入力候補一覧

Dataview で集計しやすくするため、以下の候補値を優先して使う。

## 授業ノート（template1.md）

- `period`
  - `1限`, `2限`, `3限`, `4限`, `5限`

- `source`
  - `授業`, `配布資料`, `教科書`, `動画`

- `status`
  - `未着手`, `学習中`, `復習`, `完了`

- `confidence`
  - `"1"`, `"2"`, `"3"`, `"4"`, `"5"`

- `assignment_status`
  - `未着手`, `進行中`, `提出済`

- `due`
  - `YYYY-MM-DD` 形式（例: `2026-05-10`）

- `repo`
  - GitHub URL、または Vault 内パス

## 単語ノート（term_template.md）

- `category`
  - `security`, `network`, `database`, `algorithm`, `law`, `management`

- `importance`
  - `"1"`, `"2"`, `"3"`, `"4"`, `"5"`

- `exam_priority`
  - `A`, `B`, `C`

- `exam_scope`
  - 例: `基本情報午前`, `基本情報午後`, `中間試験`, `期末試験`

- `from_note`
  - 例: `[[security_2]]`

## 命名の注意

- 同じ意味で複数表記を作らない
  - 例: `学習中` と `勉強中` を混在させない
- 迷ったらこの一覧の表記を優先する
