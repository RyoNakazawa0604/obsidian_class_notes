# 授業1回 実運用テンプレ（90分）

## 使い方
- 授業開始前にこのページを開く
- 授業ノートは `operation/templates/template1.md` から作成する
- この手順を上から順にチェックするだけで運用できる

## 0. 授業前（3分）
- [ ] ノート作成（ファイル名を命名ルールで保存）
- [ ] Frontmatter の `topic / lecture_no / period / instructor` を入力
- [ ] 今日の目標を1行で書く（例: 暗号方式の違いを説明できる）

## 1. 授業中（0〜90分）

### 速記レーン（取りこぼさない）
- [ ] 先生の強調語はそのままメモ
- [ ] 重要語が出たら `#termcard` を1行追加
- [ ] 分からない点は `Q:` で残す

### 整理レーン（理解を残す）
- [ ] `E:` 試験で問われそうな要点を追記
- [ ] `P:` 実務で使う場面を追記
- [ ] 章ごとに一言要約（1〜2行）

### ミニ用語カード記法（授業中）
```text
- [ ] #termcard 用語:  | 一言定義:  | 例:  | 重要: 試験/実務 | 転記先: [[ ]]
```

## 2. 授業終了直後（10分）
- [ ] `E:` を3つ以内に絞る
- [ ] `Q:` を「次回質問」へ移す
- [ ] `P:` を1つ以上残す
- [ ] 重要語だけ単語ノートへ転記（全部はやらない）
- [ ] 転記済み `#termcard` をチェック完了
- [ ] `status` と `confidence` を更新

## 3. 3行サマリ（必須）
- 今日の核心1:
- 今日の核心2:
- 今日の核心3:

## 4. 翌日復習（5〜10分）
- [ ] `confidence <= 2` の項目だけ見直す
- [ ] 単語ノートを3件読む
- [ ] 3行サマリを声に出して説明する

## 5. 週次レビュー（15分）
- [ ] 未転記 `#termcard` を0件にする
- [ ] `assignment_status != 提出済` を処理
- [ ] 同義語の表記ゆれを修正
- [ ] 低confidenceノートを1段階上げる
